# Status

What is done, what changed from the plan, and what is open. One file per entry in `docs/status/`, named `YYYY-MM-DD-<topic>.md`, so parallel PRs never edit the same file (see `docs/decisions/2026-10-15-shared-docs-one-file-per-entry.md`).

- **Read:** the newest entries, `ls docs/status | tail` (file names sort by date), or everything with `cat docs/status/*.md`.
- **Add:** a new file `docs/status/<today>-<topic>.md` starting with `# <date>: <title>`. Do not list it here and do not edit other threads' entries; a correction to an earlier entry goes in your own entry.
