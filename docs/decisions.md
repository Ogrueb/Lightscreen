# Decisions

Decisions, their reasons and the alternatives rejected. One file per decision in `docs/decisions/`, named `YYYY-MM-DD-<topic>.md`, so parallel PRs never edit the same file (see `docs/decisions/2026-10-15-shared-docs-one-file-per-entry.md`).

- **Read:** `cat docs/decisions/*.md` (oldest first by file name). The founding decisions are `2026-10-14-qt-6-windows-10-minimum-linux-kept-update-check.md` and `2026-10-14-vendor-singleapplication-and-uglobalhotkey.md`; the project chat's "decided, do not reopen" list is the short form.
- **Add:** a new file `docs/decisions/<today>-<topic>.md` starting with `# <date> (<context>): <decision>`. Do not list it here. A decision that replaces an earlier one says so in its own file and names the old file; the old file stays as the record.
