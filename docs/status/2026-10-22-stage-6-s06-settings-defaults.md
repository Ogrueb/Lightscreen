# 2026-10-22: Stage 6, S06 done (one default per setting)

- **New `tools/settings.{h,cpp}`:** `Settings::defaultValue`, `Settings::value` and `Settings::keys` hold one default for every option the app reads. Every reader (main window, options, preview, naming, history and area dialogs, screenshot manager) now goes through it; the remaining raw `QSettings::value` calls are state (`position`, `geometry/*`, `lastScreenshot`, `lastUpdateCheck`) and `options/optimizer`. Details and the full conflict table: `docs/decisions/2026-10-22-s06-one-default-per-setting.md`.
- **Defaults chosen (owner):** the options dialog's value for every conflict, and PNG for `file/format` (the dialog had JPEG). 13 conflicts settled: the 11 listed to the owner plus `actions/screen/enabled` and the six action hotkeys, which the window read with no default.
- **`--quit` fixed** with close-to-hide on and no tray: it exits the event loop directly instead of closing the window, which opened the "hide without tray?" box and blocked the quit. Found by the Linux smoke test once `closeHide` defaulted to on.
- **Tests, expected values changed on purpose (safety net):** `defaults.golden` `file/format=1` → `0`; `tst_Settings::windowReadsEmptySettings` `directory=<cwd>` → `<documents>/Screenshots`, `file=false` → `true`, `prefix=` → `screenshot.`; `tst_Settings::windowReadsDialogDefaults` `format=1` → `0` and so `quality=100` → `80` (PNG forces 80, bug 20). New: `tst_Settings::defaultsAgreeWithDialog` (every option the dialog writes is in the table with the value the dialog wrote) and `tst_MainWindow::quitFlagWithCloseHideAndNoTray` (fails with the old `quit()`: the dialog opened). `roundtrip.golden` unchanged.
- **Local check** (Ubuntu 24.04, apt Qt 6.4): all 12 suites pass under Xvfb; the CI smoke and hotkey smoke scripts pass (the hotkey smoke's file is now `screenshot.1.png`, the prefix default applying); include-graph and docs checks pass.
- **Not changed:** bug 20 (PNG quality forced to 80); `options/animations` still has no widget.
- **Next:** only M16 (rename) is left in the plan, blocked on the fork name; then Stage 7.
