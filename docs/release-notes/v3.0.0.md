# Lightscreen Rd 3.0.0

The first release of **Lightscreen Rd** ("Redeveloped"), a maintained fork of [Lightscreen](https://github.com/ckaiser/Lightscreen) by Christian Kaiser. Same app, same look, rebuilt on Qt 6.8 for current Windows.

Please report problems here, not to the original project.

## Highlights

- **Runs on current Windows** (10 and 11, 64-bit), built on Qt 6.8.
- **Your own upload service:** Imgur and pomf are replaced by an uploader you configure (URL, form field, headers, where the link is in the reply), with a "Test upload" button. Pomf settings from 2.5 carry over.
- **Better PNG optimization:** choose oxipng or OptiPNG (both included); files are optimized one at a time, safely, and resumed after a restart.
- **Correct capture on mixed-scaling monitors,** and pixel-exact area selection at 125% or 150% scaling.
- **About 25 bug fixes,** including a crash on upload errors with the tray icon off and file-name collisions that could overwrite a screenshot.

See [CHANGELOG.md](https://github.com/Ogrueb/Lightscreen-Rd/blob/master/CHANGELOG.md) for the full list.

## Install or upgrade

1. Download `lightscreen-rd-3.0-win64.zip` below and unzip it anywhere.
2. Run `lightscreen.exe`.

Coming from Lightscreen 2.5: your settings, hotkeys and screenshot history are picked up automatically. If you used "Run at startup", the existing entry is reused. For portable use, put a `config.ini` next to `lightscreen.exe` as before.

The release is not code-signed, so Windows SmartScreen may warn the first time you run it.

## Requirements

Windows 10 or later, 64-bit. (Linux builds from source; see `docs/build.md`.)

## Known issues

- Browsers on an HDR monitor can be captured brighter than they appear.
- PNG files always use compression quality 80.
- With fractional Windows scaling, the app's own windows are drawn at the nearest whole scale; captures are not affected.
