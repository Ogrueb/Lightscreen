# Qt 6: full pass over the app (PR #42, M09)

Use the `lightscreen-win64` artifact of the latest `master` CI run (Qt 6.8). The broad check of the app on Qt 6; upgrading from 2.5 is in `2026-10-22-rename.md`, the capture modes on mixed scaling in `2026-10-22-mixed-dpi-capture.md` and scaled displays in `2026-10-22-fractional-scaling.md`.

1. **Area drag direction.** Start an area capture and drag from bottom-right to top-left, then take another dragging top-left to bottom-right over the same spot: both images have the same size.
2. **Window capture modes.** Take one active-window screenshot and one with the window picker: each saves the expected window.
3. **Hotkeys.** The global hotkeys trigger captures with the app in the background. In Options > Hotkeys, set a hotkey by clicking the field and pressing a combination (e.g. Ctrl+Shift+F5), then set one to Print Screen: both show and work (for Print Screen on Windows 11, see `2026-10-22-fresh-install.md`).
4. **Tray and main window.** Tray icon menu opens and its entries work; the main window's buttons work; the window looks normal.
5. **Options dialog.** Change a few options, close, reopen: they stick. Export the settings to a file and import them again.
6. **History and preview.** History dialog lists screenshots and its context menu works; the preview window appears after a capture (if enabled) and drag-and-drop from it to Explorer copies the file.
7. **Portable mode.** Put an empty `config.ini` next to `lightscreen.exe`, start it: settings are stored in that file, not in the registry.
8. **Autostart.** Turn "Run Lightscreen at system startup" on, sign out and in: the app starts. Turn it off: it no longer does.
