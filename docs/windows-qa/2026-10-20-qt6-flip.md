# Qt 6: full pass over the app (PR #42, M09)

Use the `lightscreen-win64` artifact from PR #42's CI run (Qt 6.8). This is the plan's long M09 check; anything broken is a bug in M09.

1. **Upgrade keeps settings and history.** On a machine (or user account) where Lightscreen 2.5 or an earlier build of this fork has been used, with a few screenshots in the history, start the new build: the options are the ones you had (hotkeys, file name, format, folder), no first-run dialog, and View history lists the old screenshots.
2. **Area drag direction.** Start an area capture and drag from bottom-right to top-left, then take another dragging top-left to bottom-right over the same spot: both images have the same size.
3. **Capture modes.** Take one screenshot each of: whole screen, current monitor (cursor on a non-primary monitor if you have one), area, active window, window picker. Each saves the expected image.
4. **Hotkeys.** The global hotkeys trigger captures with the app in the background. In Options > Hotkeys, set a hotkey by clicking the field and pressing a combination (e.g. Ctrl+Shift+F5), then set one to Print Screen: both show and work.
5. **Tray and main window.** Tray icon menu opens and its entries work; the main window's buttons work; the window looks normal.
6. **Options dialog.** Change a few options, close, reopen: they stick. Export the settings to a file and import them again.
7. **History and preview.** History dialog lists screenshots and its context menu works; the preview window appears after a capture (if enabled) and drag-and-drop from it to Explorer copies the file.
8. **Portable mode.** Put an empty `config.ini` next to `lightscreen.exe`, start it: settings are stored in that file, not in the registry.
9. **Autostart.** Turn "Run at startup" on, sign out and in: the app starts. Turn it off: it no longer does.
10. **Scaled display.** If you have a display at 125% or 150%: area selection covers exactly the area you drag, and the window picker highlights the window under the cursor. Report any difference from the previous build.
