# The v3.0.0 release itself (Stage 7)

After the other checks pass, the release date is set in `CHANGELOG.md` and the tag `v3.0.0` is pushed.

1. **Draft.** The "Release" workflow run for the tag is green and the Releases page shows a draft "Lightscreen Rd 3.0" with `lightscreen-rd-3.0-win64.zip` attached. Paste `docs/release-notes/v3.0.0.md` (without the comment at the top) as its text and publish it.
2. **Download.** From the published release page, download the zip, unzip it and run `lightscreen.exe`: it starts and takes a screenshot (SmartScreen may warn; the release is unsigned).
3. **Update check.** Options tab > Updater > "Check Now": it shows "No new versions available." (no error now that a release exists).
