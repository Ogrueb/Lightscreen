# Rename to Lightscreen Rd (M16)

Install over (or next to the settings of) an existing Lightscreen 2.5 or an earlier fork build.

1. Start the new build: the settings and the screenshot history are the ones you had (same hotkeys, folder, history entries).
2. The main window, Options, the tray tooltip and the area/window-picker modes are titled "Lightscreen Rd"; the About tab names the fork, credits Christian Kaiser and links to both repositories.
3. With "Run Lightscreen at system startup" on, `regedit` shows one `Lightscreen` value under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, not two.
4. Right-click `lightscreen.exe` > Properties > Details: product name "Lightscreen Rd", version 3.0.
