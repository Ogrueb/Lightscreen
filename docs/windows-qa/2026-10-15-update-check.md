# Update check via GitHub Releases (PR #36, bug 6)

Optional and short. Before v3.0.0 is published; the check against the published release is in `2026-10-22-release-v3.md`.

1. Open Options, Options tab, Updater box, click "Check Now": until the fork has a published release, the dialog shows "Could not check for updates: No release has been published yet at https://github.com/Ogrueb/Lightscreen-Rd/releases". With the network off, it shows a connection error instead of "No new versions available".
2. About tab: "Lightscreen Rd on GitHub" opens the fork's repository (`Ogrueb/Lightscreen-Rd`), "Original Lightscreen" opens `ckaiser/Lightscreen`.
