# Update check via GitHub Releases (PR #36, bug 6)

Optional and short.

1. Open Options, Options tab, Updater box, click "Check Now": until the fork has a published release, the dialog shows "Could not check for updates: No release has been published yet at https://github.com/Ogrueb/Lightscreen/releases". With the network off, it shows a connection error instead of "No new versions available".
2. About tab: "GitHub page" opens the fork's repository, "Original Lightscreen on GitHub" opens ckaiser/Lightscreen.
3. Options, Upload tab: the pomf page has no "Download List" button or "View Help" link.
